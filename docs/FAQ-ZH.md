# Clio 使用方式与常见问题

## 苹果和安卓都可以用吗？

可以打开网页管理页：iPhone、iPad、安卓手机和平板都可以。

但手机不是主要服务器。Clio 通常运行在 Windows、Mac、Linux 电脑或 VPS 上，手机通过浏览器访问它。Bark 主动推送目前面向 iPhone/iPad；安卓管理页和 MCP 使用不受影响，但安卓主动推送需要以后接入其他渠道。

更完整的设备与推送对照见 [手机访问与消息推送](PUSH-ZH.md)。

## 可以完全放在本地跑吗？

可以。Docker 服务、Markdown 记忆、SQLite 数据库和向量模型都能放在自己的电脑。

不填外部 API Key 时，系统仍可保存、修改、搜索和读取记忆，也能使用网页。依赖大模型理解的摘要、裁判、事实候选、待办抽取和自然推送文案会受限。

## 本地运行必须一直开电脑吗？

是。AI 要连接 Clio 时，承载 Clio 的电脑必须开机，Docker 必须运行，电脑不能深度休眠。

希望 24 小时在线，可以迁移到 VPS。迁移的是代码、配置和 `data/`，不是重新开始一套空记忆。

## 一定要买域名吗？

本地使用不需要。

远程 MCP 最适合使用固定 HTTPS 域名，但也可以使用其他安全反向代理方案。临时隧道地址可能在进程或电脑重启后改变，不适合作为长期 MCP 地址。

## 一定要买 API 吗？

不一定。API 是智能增强，不是启动门票。

使用外部 API 时，送去摘要或裁判的文字可能离开本机。请自行阅读服务商的数据政策。也可以把 `base_url` 指向本地 Ollama、LM Studio 或其他兼容服务，但模型质量和硬件要求由使用者承担。

## AI 每次开机会把所有记忆读一遍吗？

不会。`pulse_boot` 只给核心目录与最新交接，AI 再按当前话题选择 `breath` 和 `recall`。记忆越多不等于每次开机返回越长。

## AI 读了一次桶，记忆会消失或状态会归零吗？

不会。读取是读取，不是删除。`xinchao_status` 查看状态也不会自动清零。

只有明确删除、保留期清理或人工确认的维护操作会移除数据。

## 摘要会不会把原文压缩没了？

不会。当前设计中摘要只写入独立元数据层，不允许覆盖 Markdown 正文。`hold` 和 `grow` 使用追加式写入，并有防缩水保护。

## 相似内容会自动乱合并吗？

系统可以在语义足够接近时把新内容追加到相应桶，但不调用模型重写旧正文。日期、人名等通用标签不应单独成为合并依据。自动消化只演习，不自动合并旧桶。

## 信箱和记忆桶有什么区别？

记忆桶保存比较稳定的事件、事实和感受；信箱保存窗口之间的交接话。信箱可以搜索、修改和清理，也可以参与状态理解，但不会因为“写信”就自动复制成另一份事实桶。

## 封存是什么意思？

封存内容仍保存在磁盘，但默认不会出现在搜索、开机浮现、列表和相关计数中。只有明确允许“包含封存内容”时才会读取。

封存不是加密。需要保护磁盘时，应使用操作系统账户权限、磁盘加密和安全备份。

## “激素”是真的吗？

它是一个状态模型的名字。系统用数字表示驱力、情绪倾向和时间变化，让推送、暗涌和记忆共振有可解释的依据。它不证明 AI 有人体激素，也不用于医疗判断。

## “我看到了”按钮会做什么？

它会确认一条新推送。点过后，网页会记住并隐藏这条按钮，刷新或重新登录也不会重复出现；下一条真正的新推送到来时才再次出现。

## 手机页面能永久删除记忆吗？

可以，但永久删除应先看预览并确认影响范围。删除前最好先导出，因为真正删除的目标就是释放数据，不保证能从普通历史中恢复。

## 记忆越来越多会撑满磁盘吗？

任何长期数据库都会增长。主要增长来源是原文、历史快照、模型缓存、导出和日志。建议：

- 定期导出和异地备份；
- 设置合理的信箱与已完成待办保留期；
- 审核历史快照清理报告；
- 删除不再需要的旧导出；
- 不要无确认地批量删除或合并原文。

## 如何把本地版迁移到 VPS？

1. 停止写入并做完整备份。
2. 把代码、`.env`、`config.yaml` 和 `data/` 安全传到 VPS。
3. 核对 SHA-256。
4. 在 VPS 启动并验证桶数量、随机桶原文、管理页和 MCP。
5. 公网验收完成前保留本地旧副本。

不要把私人配置和数据放进公开 GitHub 仓库。
